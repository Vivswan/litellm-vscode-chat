# LiteLLM Provider for GitHub Copilot Chat: 文件

[English](../README.md) | [简体中文](../zh-cn/README.md) | 繁體中文

本延伸模組把 GitHub Copilot Chat 連接到任意數量的 LiteLLM 伺服器: 它們的模型出現在 Copilot 的模型選擇器中, 支援串流輸出、工具呼叫、影像與推理, 延伸模組還會隨時追蹤每個伺服器的支出與預算。一切都有兩種等價的設定方式 - 儀表板面板與一般的 VS Code 設定。

## 頁面清單

依閱讀順序:

1. [入門指南](getting-started.md) - 安裝、第一個伺服器、第一次聊天, 以及最常見後續步驟的五個簡短配方。
2. [伺服器](servers.md) - 完整的 `servers` 設定: 項目欄位、三種驗證形式、祕密儲存體、各伺服器模型設定、同步生命週期、採用, 以及設定同步。
3. [模型](models.md) - 模型如何出現在選擇器中、比對鍵與繼承、能力、參數、各模型的選擇器設定, 以及有效值檢查器。
4. [用量](usage.md) - 支出與預算追蹤: 預算來自哪裡、警示、狀態列項目, 以及儀表板的用量面板。
5. [儀表板](dashboard.md) - 面板導覽: 伺服器清單與表單、模型清單、設定編輯器, 以及診斷。
6. [設定](settings.md) - 完整參考: 每個設定、其預設值, 以及舊版設定的重新命名表。
7. [疑難排解](troubleshooting.md) - 按症狀索引: 您看到什麼、它代表什麼、如何修復。
8. [開發](../development.md) (English) - 從原始碼建置, 以及用於針對真實 LiteLLM 代理測試的本機 Docker 堆疊。
