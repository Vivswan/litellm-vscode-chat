## 连接你的 LiteLLM 服务器

服务器都在 LiteLLM 仪表板中管理。添加你的服务器并填写:

- 标签: 唯一的名称; 模型选择器会将你的模型归组在它下面
- 基础 URL: 你的 LiteLLM 代理地址, 例如 `http://localhost:4000`
- API 密钥: 你的服务器不需要时留空

位于身份提供方之后的服务器可以使用 OAuth 字段代替静态密钥; 需要虚拟密钥的网关也有自己的标头字段。

你添加的每个服务器都会在聊天模型选择器中成为独立的一组模型。更喜欢纯文本文件? 仪表板写入的就是你用户设置 JSON 中的 `litellm-vscode-chat.servers` 数组; 直接编辑该数组同样有效。
