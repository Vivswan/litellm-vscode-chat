## 連線您的 LiteLLM 伺服器

伺服器都在 LiteLLM 儀表板中管理。新增您的伺服器並填寫:

- 標籤: 唯一的名稱; 模型選擇器會以它為您的模型分組
- 基底 URL: 您的 LiteLLM Proxy 位址, 例如 `http://localhost:4000`
- API 金鑰: 伺服器不需要時可留空

位於識別提供者之後的伺服器可以改用 OAuth 欄位取代靜態金鑰; 需要虛擬金鑰的閘道則有自己的標頭欄位。

您新增的每個伺服器都會在聊天模型選擇器中成為自己的一組模型。偏好純文字檔案? 儀表板寫入的是您使用者設定 JSON 中的 `litellm-vscode-chat.servers` 陣列; 直接編輯該陣列的效果完全相同。
